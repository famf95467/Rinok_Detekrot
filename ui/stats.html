Как читать цифры
Данные по заказам берутся только со страницы заказов, которую вы загрузили кнопкой. Прибыль считается по вашей себестоимости и комиссии, это оценка. «Позиция» и подсказка цены — оценка по витрине, не гарантия продаж.

Статистика v1: прибыль по лотам с наградами за отзывы

Детали заказа (ID лота и звёзды) берутся со страницы каждого заказа: по одному запросу с паузами. Уже загруженные повторно не открываются.
(ф) = факт: из заказов или вашего ввода. (о) = оценка: расчёт или правило. Выручка только по «Закрыт», возвраты отдельно. Прибыль лота = выручка − комиссия − себестоимость − награды за отзывы; прочие расходы вычитаются только в итоге по магазину.
