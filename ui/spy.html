Журнал последнего запуска


Как работает. Один гостевой запрос страницы категории, отбор лотов по словам названия и цене, порядок «популярные / дешёвые / дорогие» и первые N лотов, затем по одному запросу профиля каждого продавца (пауза 2,5–5 с). Из отзывов берутся те, где в строке «название, цена» есть слово из поля «Слово в отзывах». Без входа в аккаунт, без обхода: блокировка, капча, редирект или ошибка 401/403/429 останавливают работу до конца дня, частичный результат остаётся.


По факту: число отзывов по товару, средняя, доля 5★, плохие (1–2★), дата последнего. Считаются только просмотренные отзывы (обычно последние на странице профиля), поэтому у давних продавцов число занижено. Моя оценка: «балл» = (сумма звёзд + 3·4,0) / (число + 3): один отзыв на 5★ не обгоняет 20 на 4,9.


Профили запоминаются на 6 часов: повторный запуск по тем же продавцам не шлёт новых запросов. Ники покупателей не читаются и не сохраняются. Правила площадки проверяйте сами.
