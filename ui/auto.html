Фоновый режим: пока программа открыта, раз в несколько минут сама проверяет заказы, чаты, подтверждения, оценки отзывов и статистику, готовит текст тикета. Отправка сообщений покупателям включается отдельно по каждому виду и по умолчанию выключена: пока выключено, автопилот только показывает, сколько сообщений готово. Тикет в поддержку не отправляется никогда: его отправляете вы. Лимиты, «один раз на заказ» и остаток промокодов проверяются так же, как при нажатии кнопок.
Автоотправка (каждое сообщение уйдёт без вашего подтверждения)
Автовозврат по низкой оценке (деньги уходят покупателю, отменить нельзя)
Текст напоминания ({order} заменится на номера заказов)
Настройки сохраняются сами.
